All three issues raised for the Corporation Ownership flow (UIEP-3501) have been fixed and tested locally.
1. Foreign Country field not disabling Fixed the Foreign Country text input so it correctly greys out and locks when the "headquartered outside of the United States" checkbox is unchecked. The root cause was a missing disabled HTML attribute mapping in the shared ValidatedInput component, as well as a missing property binding on the form itself. Both have been corrected (and this proactively fixes Disabled behavior for all ValidatedInput fields across the app).
2. Missing data on the Verification Page Fixed an issue where the Verification page was silently dropping the Incorporation State and Foreign Country answers. These fields aren't part of the standard API question list, so they were getting skipped during rendering. We've added an explicit rendering block for them (similar to how we handle QSF fields) so they now display perfectly on the final summary screen.
3. Foreign Country data lost on Save & Resume Fixed a bug where a user returning to their registration via a Registration Number would find their Foreign Country blanked out. The load logic was previously ignoring the saved country if the "Outside USA" flag wasn't perfectly parsed first. We removed that restrictionâ€”the form now loads the saved country unconditionally, and automatically re-checks the "Outside USA" checkbox if a foreign country is found.
